# ATOM S3 A4988 Stepper Test

ATOM S3でA4988ステッピングモータドライバを動かす確認用サンプルプログラムです。
ベルト駆動の直動機構が1ステップずつ動くことを低速から確認できます。
AccelStepperで加減速を入れているため、起動、方向切り替え、速度切り替え時の急なステップ周波数変化を抑えます。
AccelStepperを使うACCELモードと、直接STEPパルスを出すDIRECTモードを切り替えて比較できます。

## 対応ボード

- M5Stack ATOM S3

## 配線

```text
ATOM S3                         A4988

3.3V  ------------------------  VDD
GND   ------------------------  GND
G5    ------------------------  STEP
G6    ------------------------  DIR

                                ENABLE ---- GND
                                SLEEP  ---- 3.3V
                                RESET  ---- 3.3V

12V電源 + --------------------  VBB / VMOT
12V電源 - --------------------  GND

モータ コイルA ---------------  OUT1A / OUT1B
モータ コイルB ---------------  OUT2A / OUT2B
```

| ATOM S3 | A4988 |
| --- | --- |
| G5 / GPIO5 | STEP |
| G6 / GPIO6 | DIR |
| GND | GND |

A4988のVMOT、モータ電源、モータ配線、電流制限は使用するモータに合わせて別途設定してください。
ATOM S3とA4988のGNDは必ず共通にしてください。

## 操作

- 短押し: 方向を切り替えます。
- 長押し: ステップ速度を切り替えます。
- 2秒以上押しっぱなし: ACCEL / DIRECT モードを切り替えます。

速度プリセットは `1, 2, 5, 10, 25, 50 step/s` です。
起動直後は `1 step/s` なので、直動機構が意図した方向へ1ステップずつ動くか確認しやすくしています。
ACCELモードの加速度は `30 step/s^2` に設定しています。音や振動が残る場合は `src/main.cpp` の `ACCELERATION_STEPS_PER_SEC2` を下げると、よりゆっくり速度が変わります。

## ビルドとアップロード

このディレクトリで実行してください。

```sh
pio run
pio run -t upload
pio device monitor
```

シリアルモニタは `115200 bps` です。
